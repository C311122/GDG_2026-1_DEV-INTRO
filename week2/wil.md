# 이번주에 배운 것

- 내 페이지의 글자를 꾸미는 법
  - `CSS` 사용해 보기
    ```html
    <h1 style="color: yellow;">글씨가 노란색이 된다.</h1>
    ```
  - 글씨 배경색 넣는 법과 주의점
    ```html
    <h1 style="background-color: red;">빨간색 배경색이 들어갔다, 색 뒤에 세미콜론을 붙여주자</h1>
    ```

- 텍스트를 클릭해서 다른 사이트로 들어가는 법
  - a태그 사용하기
    ```html
    <a href="./week2/C++.html">C++</a>
    ```
    상위 폴더와 들어갈 html 파일의 이름을 적어준다.

## 번외

- 깃허브 데스크탑을 사용해 커밋과 푸시를 좀 더 편하게 할 수 있었다.

### 느낀 점

- 웹사이트가 주마다 풍성해지는 것 같다.
- 대학 수업에선 배우지 못할 자잘한 팁들이 많아 유용하였다.
